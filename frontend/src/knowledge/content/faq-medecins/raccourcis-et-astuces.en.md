# Keyboard Shortcuts Guide, Language Toggling and Efficiency Tips

## 1. Objective
Empower physicians and medical administrative staff to utilize TABIBI with maximum velocity through mastery of ubiquitous keyboard shortcuts, seamless switching between French and Arabic typography with native RTL/LTR layout mirroring, and high-yield clinical input tricks.

## 2. Master Keyboard Shortcuts Table

| Shortcut Key | Function in TABIBI | Scope |
| :--- | :--- | :--- |
| **`Ctrl + K`** or **`Ctrl + F`** | Instant global patient omnibox lookup | Everywhere |
| **`F1`** | Launch interactive in-app Knowledge Base & Help | Everywhere |
| **`F2`** | Rapid New Patient Registration / Arrival Check-in | Reception desk |
| **`F9`** | Pause active consultation to triage incoming emergency | During consultation |
| **`Ctrl + P`** | Print active prescription or medical report | Document & Rx viewers |
| **`C`** | Toggle side-by-side comparative radiological split view | Document & DICOM viewers |
| **`Esc`** | Dismiss modals, floating sheets, or exit full-screen canvas | Everywhere |
| **`Tab`** | Advance focus smoothly to the next input field | Input forms |

---

## 3. Bilingual Typing & Native Right-to-Left (RTL) Architecture
- TABIBI was engineered with Arabic as a primary native language, not a superficial localization overlay.
- When typing Arabic text in diagnosis or clinical note inputs, the editor autonomously identifies Arabic characters and toggles text direction to right-to-left (`direction: rtl`).
- Windows language switcher shortcut: Press **`Alt + Shift`**.
- Mixed prescriptions: Doctors can prescribe pharmacological trade lines in French while entering posology instructions in clear Arabic (e.g. *قرص واحد قبل النوم*) to maximize patient comprehension.

---

## 4. Practical Clinical Efficiency Tricks

### A. Pre-configured Clinical Snippets
- Rather than typing repetitive benign physical exam findings (e.g., *"Cardiovascular exam regular, chest clear, abdomen soft and non-tender"*), save favorite normal templates and inject them using custom trigger tags like `#normal`!

### B. Drag-and-Drop Attachment Ingestion
- Avoid tedious file-browser dialogs; simply drag any external PDF lab report or radiological image directly from your Windows desktop onto the patient profile to ingest and archive it immediately.

### C. Waiting Room Rapid Triage
- Triage and call the next waiting patient from the queue by pressing Spacebar on the highlighted card, eliminating unnecessary mouse clicks.
